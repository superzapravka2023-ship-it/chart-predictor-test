# 🧪 Chart Predictor Test

Telegram-бот для проверки одной конкретной гипотезы: **может ли ИИ-модель
по скриншоту 5-минутного графика предсказать направление цены лучше,
чем подбрасывание монеты.**

Присылаешь скриншот — несколько моделей через OpenRouter говорят «вверх»
или «вниз». Бот записывает прогнозы, через 5 минут спрашивает, что вышло
на самом деле, и копит честную статистику по каждой модели.

**Ставок бот не делает и делать не советует.** Это измерительный прибор,
а не торговый советник.

---

## Зачем это нужно

У бинарных опционов выплата несимметрична: выигрыш даёт 70–92% от ставки,
а проигрыш забирает все 100%. Отсюда порог безубытка:

| Выплата брокера | Нужный процент попаданий, чтобы не терять |
|---|---|
| 70% | **58.8%** |
| 80% | **55.6%** |
| 92% | **52.1%** |

То есть угадывать надо не в половине случаев, а в 52–59%. Вопрос
эксперимента ровно один: способна ли модель стабильно перешагнуть эту
планку. Бот отвечает на него данными, а не рассуждениями.

## Что делает бота честным

**Доверительный интервал, а не голый процент.** 6 попаданий из 10 — это 60%
и выглядит отлично. Но такое выпадает при подбрасывании монеты примерно в
каждой третьей серии. Бот считает интервал Вилсона и признаёт перевес
только когда **вся** нижняя граница интервала оказывается выше порога
безубытка.

**Проверка против монетки.** Для каждой серии считается вероятность
получить такой результат случайно. Если она выше 0.05 — бот прямо пишет
«от подбрасывания монеты не отличается».

**Контроль незакрытых прогнозов.** Если три прогноза висят неотмеченными,
бот перестаёт принимать новые скриншоты. Это защита от главного способа
обмануть себя: отмечать только те случаи, которые запомнились, а запоминаются
обычно удачные.

**Раунды «без изменений» не идут в зачёт** — иначе они искусственно
завышали бы или занижали результат.

**Несколько моделей сразу.** Один скриншот уходит всем выбранным моделям
параллельно, статистика ведётся по каждой отдельно плюс отдельно по
случаям, когда все модели сошлись во мнении.

**Разбивка по уверенности.** Если модель угадывает одинаково и когда
заявляет 90% уверенности, и когда заявляет 55% — значит её уверенность
не несёт информации. Это видно в статистике.

---

## Моё честное ожидание

Я думаю, результат будет в районе **48–52%** — то есть неотличим от
случайности. Причины две:

1. Vision-модели неточно читают свечные графики: ошибаются в значениях,
   путают уровни, неверно считывают шкалу.
2. Даже при идеальном чтении графика в 5-минутном горизонте почти нет
   предсказуемой составляющей — цену там двигает поток ордеров, которого
   на картинке не видно.

Но это моё ожидание, а не факт. Поэтому и нужен эксперимент: если модель
даст 56%+ на выборке в 300 прогнозов, я окажусь неправ, и тогда из этого
можно делать торговый инструмент уже на основаниях.

Стоить проверка будет несколько долларов на запросы к OpenRouter вместо
депозита.

---

## Шаг 1. Ключ OpenRouter

1. [openrouter.ai](https://openrouter.ai) → регистрация
2. **Keys** → **Create Key** → скопируй, он вида `sk-or-v1-...`
3. Пополни баланс на $5–10 — этого хватит на сотни запросов

Про выбор моделей: ID моделей периодически меняются, поэтому в боте есть
команда **/models** — она запрашивает у OpenRouter живой список моделей с
поддержкой картинок, отсортированный по цене. Сменить набор можно прямо из
Telegram:

```
/setmodels openai/gpt-4o, google/gemini-flash-1.5
```

Начни с двух моделей: одной дорогой и одной дешёвой. Будет сразу видно,
даёт ли дорогая хоть что-то сверх дешёвой.

## Шаг 2. Telegram-бот

1. [@BotFather](https://t.me/BotFather) → `/newbot` → получишь токен
2. Свой chat_id: напиши [@userinfobot](https://t.me/userinfobot)
3. Напиши своему новому боту `/start`

## Шаг 3. Репозиторий

Создай приватный репозиторий `chart-predictor-test` и залей **содержимое**
папки (сами файлы, не папку целиком — иначе Render не найдёт Dockerfile).

## Шаг 4. Render

**New +** → **Web Service** → выбери репозиторий.

| Поле | Значение |
|---|---|
| Language | **Docker** |
| Region | любой — OpenRouter и Telegram доступны отовсюду |
| Instance Type | Starter |
| Health Check Path | `/health` |

**Advanced → Add Disk**: `data`, путь `/var/data`, 1 GB.

Переменные окружения:

| Key | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 2 |
| `TELEGRAM_CHAT_ID` | твой chat_id |
| `OPENROUTER_API_KEY` | ключ из шага 1 |
| `DATA_DIR` | `/var/data` |

Остальное необязательно:

| Key | По умолчанию | Что делает |
|---|---|---|
| `MODELS` | `openai/gpt-4o,google/gemini-flash-1.5` | какие модели опрашивать |
| `HORIZON_MIN` | `5` | горизонт прогноза в минутах |
| `PAYOUT_PCT` | `80` | выплата брокера, от неё считается порог |
| `MAX_PENDING` | `3` | сколько незакрытых прогнозов терпим |
| `TZ_OFFSET` | `3` | часовой пояс |

Этот бот спокойно работает и на Free-плане: ему не нужно ничего делать,
пока ты не прислал скриншот. Единственный минус бесплатного плана —
засыпание, из-за которого напоминание через 5 минут может задержаться.
Если это мешает, бери Starter.

## Как пользоваться

1. Открой график на Pocket Option, выстави 5-минутный таймфрейм
2. Сделай скриншот и отправь боту. **В подписи укажи пару**, например
   `EURUSD` — потом пригодится для разбивки
3. Через несколько секунд придут ответы моделей
4. Через 5 минут бот спросит: цена выше или ниже, чем была? Жми кнопку
5. Статистика обновится

**Важно для чистоты эксперимента:**

- Отправляй скриншот в один и тот же момент относительно свечи — например,
  сразу после открытия новой пятиминутки
- Отмечай **каждый** прогноз, включая неудачные
- Не отправляй скриншот заново, если ответ не понравился
- Выплату в настройках поставь ту, которую реально даёт брокер на этой паре

## Когда делать выводы

При выплате 80% для надёжного вывода нужно около **310 прогнозов**. Это
много, но промежуточные выводы бот даёт раньше:

| Что видишь | Что это значит |
|---|---|
| «данных слишком мало» | меньше 30 прогнозов, рано |
| «от подбрасывания монеты не отличается» | результат в пределах случайности |
| «лучше монетки, но порог не перекрыт» | что-то есть, но торговать нельзя |
| «уверенно выше порога безубытка» | вот это уже находка |
| «уверенно НИЖЕ порога» | модель систематически ошибается |

Если после 100–150 прогнозов висит «от монетки не отличается» — ответ
получен, продолжать смысла нет.

## Файлы

```
bot.py           точка входа, напоминания, health-эндпоинт
config.py        переменные окружения
openrouter.py    опрос моделей, живой список vision-моделей
stats.py         интервал Вилсона, проверка против монетки, порог безубытка
storage.py       SQLite: прогнозы, исходы, настройки
telegram_ui.py   экраны, кнопки, поток работы
```

---

Бот измеряет точность прогнозов и ничего не советует. Торговля бинарными
опционами имеет отрицательное математическое ожидание на стороне игрока
из-за несимметричной выплаты — этот бот как раз и позволяет проверить,
перекрывает ли что-нибудь этот встроенный минус. Решения о ставках
принимаешь ты сам.
